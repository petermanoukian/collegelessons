CSS Spacing, Alignment & Positioning Demo

1. Individual Directions (Margin vs. Padding)

Dashed Orange Outer Border = Wrapper boundary. Blue Border = Element edge.

Margin Individual: Moves the box AWAY from outside edges (top:20px, right:40px, bottom:30px, left:15px).
Padding Individual: Expands space INSIDE the blue border (top:20px, right:40px, bottom:30px, left:15px).

2. 4-Value Shorthand Rule (10px 0 7px 5px)

Order: Top Right Bottom Left (Clockwise direction).

margin: 10px 0 7px 5px; (Space outside the border).
padding: 10px 0 7px 5px; (Space inside the border).

3. Block Centering vs. Text Alignment

margin-left: auto; — Pushes this entire block to the right edge.

margin: 0 auto; — Centers this block box.
text-align: center; — Centers this inner text.

text-align: right; — Aligns text content to the right wall without moving the block wrapper.

4. Floats and Clearing (Float Left/Right & Clear Left/Right/Both)

Float Left

This paragraph flows around the left-floated box. The floated box is pushed to the left edge and text flows along its right side.

clear: left; — Clears the left float above, forcing this box to render underneath it.


Float Right

This text flows around the right-floated box. The floated box is pushed to the right edge and text flows along its left side.

clear: right; — Clears the right float above, placing this element strictly below it.
