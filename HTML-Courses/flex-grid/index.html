CSS Layout Comparison

1. Legacy Method: CSS Floats

Requires explicit percentages for width and a clearfix element so the container doesn't collapse.

Float Left
float: left; width: 48%;
Float Right
float: right; width: 48%;

2. Modern Method 1: CSS Flexbox (1-Dimensional)

Items align automatically side-by-side using display: flex and evenly distribute width using flex: 1.

Flex Box 1
display: flex;
Flex Box 2
flex: 1;
Flex Box 3
gap: 15px;

3. Modern Method 2: CSS Grid (2-Dimensional)

Columns and rows are defined on the parent container using grid-template-columns.

Grid Item 1
display: grid;
Grid Item 2
grid-template-columns:
Grid Item 3
repeat(3, 1fr);
